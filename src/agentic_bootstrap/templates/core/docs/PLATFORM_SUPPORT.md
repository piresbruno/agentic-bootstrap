## Portable Core

All selected platforms share provider-neutral project instructions, task workflow, ADRs, deterministic validators, and Agent Skills where natively supported. The project-scoped `agentic-bootstrap` skill is advisory: it stops after preview and requires separate human-terminal apply. OhMyPi (omp) consumes the portable core natively; its adapter generates only the sticky `RULES.md` invariant file at `.omp/RULES.md`.

## Optional Features

- MCP is generated only when explicitly selected.
- Specialized agents are generated only when explicitly selected.
- Repository-hosting workflows and Git hooks are opt-in.
- Hooks never invoke an LLM or perform bootstrap mutation.
- The security-audit skill is documented but never generated or auto-installed; install it on demand per `docs/SECURITY_AUDIT.md`.
- The planning-and-task-breakdown and create-tickets skills are documented but never generated or auto-installed; install them on demand per `docs/TASK_BREAKDOWN.md`.
- Pi MCP and subagent parity require separately reviewed extensions; they are not native capabilities.

## Verification

Static adapter contract tests validate syntax and discovery paths. Release smoke tests should record the exact CLI versions and date used for instruction and skill discovery.
